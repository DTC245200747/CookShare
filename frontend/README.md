# CookShare frontend

React 19 + TypeScript + Vite. `npm ci`, `npm run build`, hoặc `npm run dev` để hot reload tại cổng 5173. Proxy API/upload về backend cổng 3000. Sau build, backend local hoặc Nginx Docker phục vụ `dist`. Xem [README gốc](../README.md) để cấu hình DB, auth, tests và khởi động đầy đủ.
